# Pipeline Drill 01

## Purpose
Use regex to extract structured fields from raw log lines and produce a clean CSV for analytics or ingestion.

## Extracted fields
- timestamp  
- log level  
- username  
- IP address  
- action  

## Process
We use a regex pattern to:
- parse each log line into the fields above  
- normalize the username (lowercase)  
- write all rows into `clean_output.csv` with headers

## Regex Explanation
Regex Explanation
We use a single compiled regex pattern to extract structured fields from each log line:
timestamp — captured from inside square brackets
log level — matches one of ERROR, INFO, or WARNING
username — captured after User:
IP address — matches four numeric octets separated by dots
action — captured after Action:

The regex breaks each log line into these components, allowing us to normalize the username and write a clean, structured CSV ready for analytics or ingestion.
