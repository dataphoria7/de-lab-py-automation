# DE Lab — Regular Expressions Log Parser
This project demonstrates how to use Python's `re` module to extract structured data from messy log files.									
                                    
## Business Problem									
                                    
Security needs to identify:									
- users with repeated login failures									
- suspicious IP addresses									
- patterns of user activity									
                                    
The raw logs are unstructured and cannot be loaded directly into a database.									
                                    
## Solution									
                                    
We use regex to extract:									
- timestamp									
- log level									
- username									
- IP address									
- action									
                                    
Then we normalize the data and output a clean CSV ready for analytics or ingestion.									
                                    
## Files									
                                    
- `sample_logs.txt` — small sample of raw logs (local working file)									
- `log_parser.py` — ETL script that parses and normalizes logs									
- `clean_logs.csv` — structured output generated by the script									
                                    
## How to Run									
                                    
python log_parser.py
